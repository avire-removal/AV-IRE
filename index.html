AV-IRE: Instruction-Routed Audio-Visual Subject Removal

Each input contains two audible performers. The two instructions, qA and qB, name different targets in the same recording. A correct edit removes only the instructed performer from both video and audio while preserving the other performer, the background, and all non-target sounds.

How to read each example. First play the shared input, then compare the five system outputs under qA and qB. Switching from qA to qB changes only the named target. The paired outputs therefore show whether a system follows the instruction rather than applying the same edit to both requests.
Blind-review legend
VR target visually removed AR target sound removed VP other performers preserved AP other sounds preserved C audio and video consistent J all five criteria pass

A check means that the displayed system output passed the criterion; a cross means that it did not. J passes only when all five criteria pass for that output. A wrong-source flag means that the edit removed a non-target source.

Evaluation, media, and anonymity details

Systems and rating scope. Task-adapted LTX-2.5 is the same-backbone control: it uses the LTX-2.5 backbone, a 6,000-step task LoRA, and a target-specific text prompt, but does not use the AV-IRE selector or routing executor. AV-IRE and this control were judged in the final blind-review round. InstructAV2AV badges report an earlier blind-review round on the same Natural-2 queries. Kiwi-Edit to CoherentAVEdit and LTX-2.5 no-LoRA are labeled “automatic evaluation only” because this displayed subset has no human ratings for those systems.

Example selection. Section 1 contains all five inputs for which AV-IRE passed both target requests in the final blind review. Section 2 contains six inputs selected with a fixed random seed and kept regardless of outcome. These examples provide qualitative comparisons; aggregate results and statistical analyses are reported in the paper, and the complete item-level judgments are included in the supplementary material.

Media provenance. AV-IRE and task-adapted LTX-2.5 reuse the exact outputs shown in the final blind review. InstructAV2AV reuses the exact outputs from an earlier blind-review round on the same queries. LTX-2.5 no-LoRA reuses its evaluation outputs. Kiwi-Edit to CoherentAVEdit outputs were converted from MP4V to H.264 only for browser playback; the underlying frames and audio were not regenerated. Every input is shown as 121 frames at 30 fps, matching the output window.

Anonymity. This page contains no author names, affiliations, external links, or analytics code. All media and styles are served with the page.
